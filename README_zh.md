# omp-cursor

在 [Oh-My-Pi (OMP)](https://omp.sh) 原生输入框里，直接用鼠标点选光标、划词高亮和批量编辑。

---

## 为什么写这个

在终端里用 OMP 敲长草稿、贴代码或者写复杂的提示词时，如果中间敲错了一个词，往往得狂按十几下甚至几十下方向键才能把光标挪过去。

这个插件给 OMP 的主输入框加上了鼠标支持：
- 鼠标点哪，光标就跳到哪；
- 拖拽就能划词高亮，双击选中单词，三击选中整行；
- 划选后直接打字就能替换，按 Backspace 就能整段删除；
- 不需要跳出全屏弹窗，改完按一下 Esc 恢复键盘打字。

---

## 常用操作

| 操作 | 对应手势 / 按键 | 说明 |
| :--- | :--- | :--- |
| **激活模式** | `Alt+E` | 状态栏图标从 `⌨` 切为 `🖱`，开始接收鼠标操作 |
| **光标定位** | 鼠标单击 | 精准落位。汉字和 Emoji 自动按单元格对齐，不会点偏 |
| **划词高亮** | 鼠标拖拽 | 反显选中内容 |
| **快捷选择** | 鼠标双击 / 三击 | 双击选词，三击选中整行 |
| **选区编辑** | 直接敲字 / `Backspace` | 选中文字后直接输入新内容覆盖，或按退格整段删除 |
| **复制文本** | `Ctrl+C` | 有选区时，将选中的文本拷入系统剪贴板 |
| **保存并退出** | `Esc` 或 `Alt+E` | 保存所有修改，退出鼠标模式（切回 `⌨`） |
| **放弃并还原** | `Ctrl+D` | 丢弃本次鼠标编辑的改动，将草稿回退到进入前的状态 |

## 模式指示符 (`/cursor`)

在 OMP 输入框顶栏的状态线上，插件占用的是和内置 Vim 模式完全一致的第二槽位（`π > ⌨/🖱 > 主机名 ...`）。

你可以随时在聊天框输入 `/cursor` 命令切换展示样式：

- `/cursor icon`（默认）：平时显示暗色 `⌨`，按 `Alt+E` 激活后切为高亮青色 `🖱`；
- `/cursor text`：文本模式，平时显示 `[KB]`，激活后切为 `[MOUSE]`；
- `/cursor hidden`：极简模式，隐藏图标，但点选和划词功能依然生效。

---

## 与 Vim 模式共存

如果你在 OMP 中开启了内置的 Vim 模式（`tui.vim: true`）：

插件会自动检测并主动让出所有控制权。`Alt+E` 不会抢占输入，鼠标事件不会干扰 Vim 的移动与操作符逻辑，确保两个模式互不打架。

## 一点实现细节

很多给命令行写鼠标支持的做法，遇到困难就直接弹一个全屏浮层。这样写虽然省事，但一弹窗就会抹掉终端原有的彩色 Logo、聊天气泡和背景底色，割裂感很强。

`omp-cursor` 没有走弹窗路线：
1. **原地接入**：继承 OMP 的 `CustomEditor`，在正常的终端屏幕缓冲区内直接接管编辑器组件；
2. **事件抢断**：通过 `capturesInput` 在宿主事件分发前拦截 SGR 鼠标报文；
3. **选区注入**：利用官方的 `decorateText` 和 `applyHostEdit` 接口，在保留原生边框与主题的同时，注入高亮选区与光标跳转；
4. **字宽计算**：汉字在终端占两列，但底层字符串只占一个长度。我们按 Unicode Grapheme 簇重新计算了单元格映射，彻底解决了点击中文时“点第二个词跳到第四个词”的错位问题。

## 局限与注意

- **终端原生划选复制**：当鼠标模式激活时，终端为了把坐标报给程序，会接管局部的鼠标点击。如果这时你想用终端原生手势划选上面的聊天文字，按一下 `Esc` 退出鼠标模式，或者按住终端的 `Shift` 键即可正常划词复制。

## 安装方法

### 方式 A：一行命令官方插件安装（最推荐）

任何 OMP / Pi 用户只需在终端执行一行命令，自动下载依赖并常驻就绪：

```bash
omp plugin install github:gongquan45/omp-cursor
```
*(如果使用的是 Pi 原版，命令同样为 `pi plugin install github:gongquan45/omp-cursor`)*

---

### 方式 B：手动克隆至 OMP 扩展目录

```bash
# 1. 克隆到 OMP 插件目录
git clone https://github.com/gongquan45/omp-cursor.git ~/.omp/agent/extensions/omp-cursor

# 2. 安装依赖
cd ~/.omp/agent/extensions/omp-cursor
bun install
```

### 方式 B：在配置文件中指定本地路径

如果你把代码克隆在其他自定义目录，可以在用户主配置文件 `~/.omp/agent/config.yml`（Windows 对应 `%USERPROFILE%\.omp\agent\config.yml`）中添加插件绝对路径：

```yaml
extensions:
  - /path/to/omp-cursor
```
